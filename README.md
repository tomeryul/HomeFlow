# HomeFlow 🏠 — אפליקציית ניהול מעבר דירה (ייבוא/ייצוא, בלי מסד נתונים)

אפליקציית ווב בקובץ HTML יחיד לניהול מעבר דירה. **בלי התחברות ובלי מסד נתונים** —
מייבאים את הקבצים בתחילת כל ישיבה, עובדים בנוחות (עריכה, הוספת משימות, סימון
סטטוסים), ובסוף מייצאים בחזרה לקובץ Excel.

## איך זה עובד

1. **פותחים את `index.html`** בדפדפן (אין צורך בשרת).
2. **ייבוא** — גוררים או בוחרים:
   - קובץ **Excel (.xlsx)** עם הגיליונות של המעבר (קניות, משימות, התקנות, אריזה,
     קניות לסופר וכו').
   - קובץ **PowerPoint (.pptx)** של לוח הזמנים היומי.
   האפליקציה קוראת את שני הקבצים וממלאת את הלשוניות המעוצבות.
3. **עובדים** — עריכת סטטוסים, מחירים, הערות, תאריכים; הוספה/מחיקה של פריטים
   ומשימות; חיפוש וסינון. הכול נשמר אוטומטית בדפדפן (localStorage) כדי שרענון
   באמצע ישיבה לא ימחק עבודה.
4. **ייצוא** — כפתור **📤 ייצוא ל‑Excel** מוריד קובץ `.xlsx` מעודכן, כולל את
   **לוח הזמנים כגיליון נוסף** בתוך אותו קובץ.

## לשוניות

לוח בקרה · משימות (דירה ישנה/חדשה) · הובלות והתקנות · קניות · קניות לסופר ·
תקציב · ארגזים · לוח זמנים.

## מיפוי הקבצים

- `קניות` → לשונית **קניות** (מחיר, ספק, סטטוס, קישור, מספר הזמנה)
- `תיאום התקנות והרכבות` → **הובלות והתקנות** (סטטוס 4‑שלבי, תאריך, עלות הובלה)
- `משימות` + `משימות- חדש` + `אחרי המעבר` + `סידור והרכבת רהיטים` → **משימות**
  (חלוקה לדירה ישנה/חדשה לפי הקטגוריות שבקובץ)
- `רשימת קניות לסופר` → **קניות לסופר**
- `טבלת אריזה של ארזים` → **ארגזים**
- `אנשי קשר` → כרטיס מידע בלוח הבקרה
- לוח הזמנים מה‑**PowerPoint** → לשונית **לוח זמנים** (ובייצוא — גיליון `לוח זמנים`)

## פרטיות

אין חשבונות ואין שרת. כל הנתונים חיים רק בדפדפן שלכם עד שאתם מייצאים. כדי לעבור
מחשב/דפדפן — פשוט מייצאים בסוף ומייבאים בהתחלה.
