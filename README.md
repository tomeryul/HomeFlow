# HomeFlow 🏠 — אפליקציית ניהול מעבר דירה

אפליקציית ווב מלאה (קובץ HTML יחיד) לניהול מעבר דירה מנווה עוז, פתח תקווה →
פסגת אפק ב', ראש העין — ל-13/08/2026. ממשק בעברית מלא עם תמיכת RTL, התחברות,
ניהול חברי צוות עם הרשאות, ושמירת כל הנתונים ב-Supabase.

## תכונות

- **התחברות / הרשמה** מאובטחת (Supabase Auth).
- **ניהול פרויקט ומשתמשים** — מנהל הפרויקט יכול להזמין אנשים לפי אימייל ולהגדיר
  להם הרשאה:
  - 🔑 **מנהל** — שליטה מלאה, כולל ניהול חברים ואיפוס.
  - ✏️ **הרשאה מלאה** — הוספה/עריכה/מחיקה של משימות ופריטים.
  - 👁️ **הרשאה מוגבלת** — עדכון סטטוסים בלבד.
- **7 לשוניות**: לוח בקרה, משימות, הובלות והתקנות, קניות, קניות לסופר, תקציב, ולוח זמנים.
- **2 ספירות לאחור** בכותרת — לקבלת המפתח (30/07) וליום המעבר (13/08).
- **משימות מופרדות לפי דירה** — דירה ישנה (אדום, 4 קטגוריות) מול דירה חדשה (ירוק, 6 קטגוריות).
- **לשונית הובלות והתקנות** — סטטוס 4-שלבי (ממתין/תואם/בדרך/בוצע), תאריכים והערות עריכים;
  עדכון כאן מסונכרן מיידית ללשונית התקציב.
- **לשונית קניות** — כל הפריטים מהאקסל ב-6 קטגוריות, עם קישורים, מחירים, מספרי הזמנה וסטטוס.
- **לשונית תקציב** — סיכום הוצאות (₪38,247 מוצרים + ₪3,890 הובלות), 9 כרטיסי קטגוריה עם
  פירוט בלחיצה.
- **לוח זמנים ויזואלי** — ציר זמן אנכי עם צמתים צבעוניים ותגיות קטגוריה לכל משימה.
- כל הנתונים יובאו מקובץ ה-Excel של המעבר.
- חיפוש חופשי + סינון לפי סטטוס ועדיפות בכל הלשוניות.
- סרגלי התקדמות לכל חדר/קטגוריה, ספירה לאחור, טולטיפים להערות (💬).
- שמירה מיידית ל-Supabase + מטמון מקומי (localStorage) לטעינה מהירה ולעבודה גם
  כשהרשת איטית.
- עדכונים בזמן אמת (Realtime) — שינויים של חבר צוות אחד מתעדכנים אצל האחרים.

## הרצה

זהו קובץ יחיד וללא צורך בשרת — פותחים את `index.html` בדפדפן, או מארחים אותו
בכל שירות סטטי (GitHub Pages, Netlify, Vercel וכו'). התלות החיצוניות היחידות
הן ספריית `@supabase/supabase-js` ופונט Rubik, שנטענות מ-CDN.

```
# הרצה מקומית מהירה
python3 -m http.server 8000
# ואז גלישה אל http://localhost:8000
```

## Backend (Supabase)

הנתונים נשמרים בפרויקט Supabase. הסכימה כוללת את הטבלאות:
`projects`, `project_members`, `tasks`, `room_items`, `timeline_items`.

אבטחה: **Row Level Security** מופעל בכל הטבלאות. הגישה מוגבלת לחברי הפרויקט בלבד,
והרשאות כתיבה נאכפות לפי תפקיד (manager / full / limited) באמצעות פונקציות עזר
מסוג `SECURITY DEFINER` (כדי למנוע רקורסיה ב-RLS).

הקונפיגורציה נמצאת בראש בלוק ה-`<script>` שב-`index.html`:

```js
const SUPABASE_URL = "https://zaikfsmkogejrtqdmbll.supabase.co";
const SUPABASE_KEY = "<publishable key>"; // מפתח פומבי — בטוח לחשיפה בצד הלקוח
```

> **הערה — אימות אימייל:** כברירת מחדל Supabase שולח מייל אישור בהרשמה.
> כדי לאפשר התחברות מיידית ללא אישור, ב-Dashboard:
> *Authentication → Sign In / Providers → Email →* כבו את *"Confirm email"*.
> בכל מקרה האפליקציה מטפלת בשני המצבים ומציגה הודעה מתאימה.
