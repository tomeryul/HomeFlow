# HomeFlow 🏠 — עורך מעבר דירה (נאמן לקובץ, בלי מסד נתונים)

אפליקציית ווב בקובץ HTML יחיד לניהול מעבר דירה. **בלי התחברות ובלי מסד נתונים.**
מייבאים את הקבצים בתחילת כל ישיבה, עורכים בנוחות, ובסוף מייצאים חזרה לאותו קובץ
Excel — **עם אותן עמודות ואותם ערכים בדיוק**.

## איך זה עובד

1. פותחים את `index.html` בדפדפן (אין צורך בשרת).
2. **ייבוא** — גוררים או בוחרים קובץ **Excel (.xlsx)** ואת לוח הזמנים
   **PowerPoint (.pptx)**. אפשר לבחור את שניהם יחד.
3. **עריכה מודולרית** — כל גיליון מהקובץ הופך ללשונית נפרדת עם טבלה לעריכה:
   - עריכת כל תא (הערכים תואמים לקובץ במדויק).
   - שינוי שמות עמודות, הוספה/מחיקה של עמודות ושורות.
   - עמודות "סטטוס" מקבלות צביעה אוטומטית (בוצע/בתהליך/לא בוצע) — לפי שם העמודה,
     בלי לקבע מבנה.
   - **מודולרי לחלוטין** — אם מוסיפים עמודה בקובץ, האתר ממשיך לעבוד. שום מבנה
     עמודות לא מקובע בקוד.
   - הכול נשמר אוטומטית בדפדפן (localStorage) — רענון באמצע ישיבה לא מוחק עבודה.
4. **ייצוא** — כפתור **📤 ייצוא ל‑Excel** מוריד קובץ `.xlsx` **תואם לקובץ שיובא**:
   אותם גיליונות, אותן עמודות, אותם ערכים (+ העריכות שלכם, + הלו״ז כגיליון).

## לשוניות

- **📊 סקירה** — כרטיס לכל גיליון עם מספר שורות/עמודות ואחוז ביצוע (כשיש עמודת סטטוס).
- **לשונית לכל גיליון** מהקובץ — טבלה נאמנה לעריכה.
- **➕ גיליון** — הוספת גיליון חדש ריק.

לוח הזמנים מה‑PowerPoint מיובא כגיליון **לוח זמנים** (תאריך, יום, ספירה לאחור,
משימות) — ניתן לעריכה ומיוצא בתוך אותו קובץ Excel.

## פרטיות

אין חשבונות ואין שרת. הנתונים חיים רק בדפדפן שלכם עד לייצוא. כדי לעבור בין
מחשבים — מייצאים בסוף הישיבה ומייבאים בתחילת הבאה.
